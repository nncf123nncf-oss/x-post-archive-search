# 自分のXの過去投稿を検索・被り確認

Xからダウンロードした自分の投稿データ（tweets.js）を選ぶと、過去投稿の検索・下書きに似た過去投稿の確認・よく使うタグと言葉の偏りの表示が、ブラウザの中だけでできるWebページです（100日100プロダクト Day062）。

- 選んだファイルと下書きは端末の中だけで処理し、保存しません（毎回ファイルを選び直します）
- AI・外部APIは使っていません。似ている度合いは文字の重なり（2文字ずつ）の目安で、同じ内容かどうかは判断しません
- 画面・サンプルの投稿は架空のカフェ店主のもので、実在の人・投稿ではありません

## 限界・未確認
- アーカイブの形式（先頭が `window.YTD.tweets.part0 = `、各要素が `{ "tweet": {...} }`、数が文字列）は第三者の解説による想定で、Xの公式資料では確認していません。実際のファイルで形式が違う場合は読み込まず理由を表示します
- 実際のアーカイブ・iPhone・Androidでの「ファイルを選ぶ」操作は未確認です
- 言い回しが違う同じ話は見つけられません

## 検算
- `node source/run-checks.js`（計算コア）
- `node source/e2e.js`（Chromeのヘッドレス実行で画面操作・375px）
- `node source/make-sample.js`（架空のサンプル tweets.js を生成）
